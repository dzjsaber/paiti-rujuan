# 构建验证产物（builds/）

本目录保存开发过程中各次代码变更后的 **Expo Android 导出产物**，用于确认当时代码可正常构建。

- 每个 `dist-*` 子目录对应一次变更，目录内的 `README.md` 标明对应的提交与改动内容
  （GitHub 上点进目录会自动展示）。
- 每个子目录内容为 `.hbc`（JS bundle）与 `metadata.json`，与应用运行、数据备份无关，可安全忽略。
- `dist-m1*` 系列仅在本地留存（被 .gitignore 忽略，不随仓库发布）。
- 后续重新导出验证时，输出到 `builds/dist-<新序号>`，保持仓库根目录整洁。
