# 拍题入卷 M0 实测报告

- 日期：2026-10-15（Asia/Shanghai）
- 执行：独立验证脚本 `m0_check.py`（本目录）+ 真实账号 API 调用
- 样本：用户提供的 10 张真实试卷图片（`samples/`）
- 口径说明：识别质量部分为代理对照原图的初步核对，最终验收需用户复核
- 核验原则：免费政策与模型可用性以本日实测为准，非永久承诺

## 1. 结论摘要

1. **Base64 直传可行**：不经过任何第三方图床，图片可直接发给智谱接口（裸 Base64 与
   data URI 两种格式实测都能被模型读到；脚本默认裸 Base64）。
2. **推荐锁定**：视觉 `glm-4.6v-flash`、文本 `glm-4.7-flash`，两者实测可用。
3. **免费池存在间歇性 1305（平台过载）**：10 张样本首次通过 8 张，补跑后 10/10 全覆盖。
   必须保留"退避重试 + 失败页补跑"机制，且不得无间隔连续重试。
4. **备选免费视觉模型 glm-4.1v-thinking-flash 质量不合格**：10 张全部返回 200，但双栏页
   只提取 1/6 题且 JSON 损坏，化学页与倾斜页返回空数组，输出中思考过程混入正文。
   不建议作为一期引擎（仅可作为观察项）。
5. **模型 JSON 输出存在三类缺陷**，ResponseParser 已实现有限修复并通过 19 项自测：
   - Markdown 围栏包裹（最常见）；
   - 字符串内裸换行（多行公式）；
   - 未转义的 LaTeX 反斜杠（`\(`、`\frac`、`\left`；其中 `\b\t\r\f` 开头会被 JSON
     静默解析成控制字符，属"不报错但产生错误数据"的隐性风险）。
6. **模型自评 confidence 全部为 0.0**（101 条草稿无一例外）：不能依赖 confidence 分级，
   阈值策略必须结合 F2 的确定性规则，全部高风险题进入人工复核（与产品设计一致）。
7. **非选择题真实存在且超出枚举**：填空题、解答题、操作题会被 F2 正确拦截；一期 UI
   必须明确提示"暂不支持非选择题型"。

## 2. 模型可用性实测

| 模型 | 类型 | 实测结果 |
| --- | --- | --- |
| glm-4.6v-flash | 视觉（免费） | 可用；12 次识别请求中 3 次返回 1305，重试/补跑后全部成功；单页耗时 13-77s |
| glm-4.1v-thinking-flash | 视觉（免费） | 接口可用但质量不合格（见第 1 节第 4 条） |
| glm-4.5-flash / glm-4-flash-250414 | 文本（免费） | 可用（最小请求 200） |
| glm-4.6v-flashx / glm-4.6v | 视觉（付费） | 未实测（免费模型达标前不引入付费兜底） |
| glm-4.7-flash | 文本（免费） | 可用（7.3s，正常输出；思考内容在独立 reasoning_content 字段） |

1305 语义（官方文档 + 实测一致）：HTTP 429，"该模型当前访问量过大"，属可重试类；
无 Retry-After 头返回。实测为间歇性（同一分钟内不同样本有成功有失败），非账号封禁、
非欠费（欠费为 1113）。

## 4. 解析层（ResponseParser）实测发现与修复

| 现象 | 例子 | 处理 |
| --- | --- | --- |
| Markdown 围栏 | ```json ... ``` | 去围栏后解析（fenced） |
| 字符串内裸换行 | stem 中多行公式 | 控制字符转义（_repaired） |
| 未转义 LaTeX 反斜杠 | `\(`、`\ln`、`\frac`、`\begin` | 字面反斜杠转义（防 `\f` 等被静默解析为控制字符） |
| 外层 JSON 损坏 | 03 政治页曾出现"数组 + 说明文字 + 裸对象" | 只提取顶层平衡数组；**禁止**把嵌套片段（如某题 options 数组）当作题目列表返回 |
| 思考标签混入正文 | `<think>...</think>` 前缀 | 解析前剥离 |

自测：19/19 用例通过（含截断、非法转义、嵌套陷阱、重复题干、多选压字符串等反例）。
严格 JSON 占比：0/12（模型从不输出严格 JSON）；有限修复后可解析 12/12。

## 5. F2 校验层分布（101 条草稿）

- passed = 0；needs_review = 42；invalid = 59
- issue 分布：V6 置信度=0（42）、V8 答案缺失（42）、V1/V2 类型非法（22：解答/填空/操作）、
  V3 选项问题（19：选项为空或不足 2 个）、V4 题干为空/过短（18）、V7 视觉特征提示（3）、
  V5 疑似重复（1）
- 解读：passed=0 是"confidence 全 0 + 题目页普遍无答案"两个因素叠加的必然结果，
  不是校验层错误；无效题主要是答案页与枚举外题型，拦截符合预期。

## 6. 关键风险与 M1 建议

1. **1305 应对**：串行 + 请求间隔 ≥1s + 单请求最多重试 1 次（退避 20s）+ 失败页集中补跑；
   UI 上如实显示"平台繁忙，稍后补跑"，禁止无间隔重试。
2. **倾斜/折痕拍摄**：08 暴露的漏题与拍照质量直接相关。M1 需在预处理阶段做
   自动旋转/透视校正评估；兜底链路（切半、框选）要在 M1-D 用同类样本验证。
3. **confidence 不可用**：全部 0.0，说明"模型自评"不能作为唯一分级依据；
   复核原因必须以 F2 规则为主、模型标记为辅（与文档 §3.1 一致）。
4. **题型范围**：真实样本中填空题/解答题/操作题占比高（09、06 部分、08）。
   一期只支持 single/multiple/judge，需在 F3 与文档中明确提示，避免用户误解。
5. **答案页价值**：04/05 证明"题号→答案字母"可被稳定提取，可作为 F8 文档答案表映射的
   参考路径；但需与题目页分离处理，不能混入题库。
6. **字符级错误**（苹果→草果、题号拆分）F2 无法发现，必须依赖 F3 原图对照与用户确认。
7. **免费政策时效**：以上可用性与免费状态核验于 2026-10-15，进入 M1 前若跨周需复测。
