# 视觉模型对比实测（2026-10-15）

用于"设置 → 识别模型"档位选型。测试条件：同一张真实试卷（`11_负数分数.jpeg`，
2022 武汉中考数学卷，两页拼接、1080×762）、同一识别 prompt、桌面验证脚本
（`tools/m0_check.py` 同源逻辑，temperature=0.1，thinking=enabled）。
人工对照原图逐题核对。

## 结果

| 维度 | glm-4.6v-flash（免费） | glm-4.6v（付费） | glm-4.6v-flashx（付费） | glm-5.3-flash（付费） |
| --- | --- | --- | --- | --- |
| 耗时/页 | 74s | 76s | **36s** | **473s** |
| 官方价格（元/百万 tokens） | 免费 | 1 / 3 | 0.15 / 1.5 | 0.8 / 2.8 |
| 输出格式 | 围栏 JSON（需修复） | 严格 JSON | 围栏 JSON（LaTeX 混入） | 严格 JSON |
| 幻觉（编造题目） | **出现**（汉字题被替换为虚构题） | 无 | 无 | 无 |
| 选项错位 | 出现（彩票题 B/C 互换） | 无 | 出现（B/C 改写错） | 无 |
| 指数/符号识别 | 正确 | 部分错误（指数读错） | 部分错误 | **正确** |
| 题干干净度 | 一般（"四边选材料"） | 一般（"四边形材料"） | 差（"对现象无不在"、"马位上"） | **好** |
| 图形选项处理 | 空文本 | 空文本 | 占位"(A)(B)(C)(D)" | 标注"（图形选项，见原卷）" |

## 结论（已用于产品档位）

1. **免费档 glm-4.6v-flash 保留为默认**：速度与付费版相当，但有编造题目的实例，
   必须在确认页认真复核。文案不得宣称"免费版更慢"——实测速度无差异。
2. **高级档采用 glm-4.6v**：与免费档同速、质量明显更稳（幻觉与错位消失）、
   费用约 0.01 元/页（按输入 1 元、输出 3 元/百万 tokens 估算）。
3. **glm-4.6v-flashx 不提供**：快一倍但题干错乱严重，质量不达标。
4. **glm-5.3-flash 不提供**：质量最高但约 8 分钟/页（深度思考消耗），
   不适合拍照识别的交互场景；且实测 8192 max_tokens 会被思考耗尽导致空输出，
   必须 ≥32768。
5. 第 6 题选项 A/B 已由用户对照原图确认（A 为 `y₁+y₂<0`）：`glm-4.6v` 正确，
   免费版（A 错读为 y₁<y₂）与 5.3-flash/flashx（A/B 对调）均错误。
   单样本结论，后续 M1-D 回归测试扩大样本量。

## 补充测试：符号密集题（2026-10-16，prompt v2）

用户实测发现免费档在符号题上出错（绝对值内外层次丢失、不等号/等号混淆），
用 10 号测试卷（带批注月考卷）在同一 prompt（v2，新增"数学符号逐字符精确转写"规则）
下重跑两档对比：

| 题 | 内容 | 免费 glm-4.6v-flash | 高级 glm-4.6v |
| --- | --- | --- | --- |
| 第 3 题 | 判断"不相等"的表达式组 | A=(-3)¹和-3¹（指数错）；D=且残缺失括号 `\| -2\|³ 和 \|-2\|` | A=(-3)²和-3²；**D=\|-2\|²和\|-2²\|（绝对值内外结构正确）** |
| 第 4 题 | 分式运算判断 a/b/c 关系 | 选项 A 与 D 完全重复、不等号组合混乱 | **A=a≠c,b≠c / B=a≠c,b=c / C=a=c,b≠c / D=a=c,b=c（四组合完备）** |
| 第 5 题 | 图形选项 | 选项全空 | 占位"图形A/B/C/D"（可被 F2 图形检测识别） |

结论：**符号密集的数学题，高级档（glm-4.6v）明显更可靠**；prompt v2 已上线
（对两档均无害，高级档受益明显）。免费档适合文字型题目（政治/判断题等），
数学卷建议使用高级档。单样本对比，后续 M1-D 回归时扩大样本量。
