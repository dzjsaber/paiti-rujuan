# 拍题入卷（PaiTi RuJuan）

面向个人备考的 Android 刷题工具：**拍照 / 导入文档 → AI 提取题目 → 本地题库 → 刷题 / 错题本 / 收藏 → AI 讲解（带教材引用）**。

离线优先：题库、图片与教材默认全部保存在手机本地（SQLite）；另提供可选的 FastAPI 云端备份服务，用于换机或多设备迁移。AI 能力由使用者自备的模型 API 直接驱动（智谱 / DeepSeek / 任意 OpenAI 兼容接口可切换）。

## 功能一览

### 题目采集

- **拍照识别**：整页试卷拍照或相册选图，压缩后交给视觉大模型识别为结构化题目（单选 / 多选 / 判断 / 填空简答）；整页失败自动切半重试，支持手动框选局部重识别、双指缩放查看原图
- **自动配图**：模型标注题目中的图形区域坐标，自动从照片裁出题干图 / 选项图入库，可人工重截修正
- **文档导入**：PDF / DOCX / PPT / PPTX / TXT / MD 本地提取文本 → 云端结构化切题；支持文末答案表映射、漏题检查、提取预览手动修正、切题中断
- **答案补齐**：从答案文档解析"题号 → 答案"（支持逐行式、"1-5 DCBAB"区间连写等格式，本地解析失败时 AI 兜底规范化），批量补充缺答案的题目

### 题库管理

- 多题库体系：新建 / 重命名 / 删除题库，入库时选择目标库
- 题库可**绑定多本教材**（非强制），绑定的教材成为该库 AI 讲解的依据来源
- 题目编辑：题干、选项、答案、自带解析

### 练习

- 顺序 / 随机刷题；单选与判断即时判定、多选提交判定、填空简答文本作答（全角/标点/大小写规范化匹配）
- **收藏**与"只刷收藏"模式；题目列表可跳转任意一题
- 错题本：答错自动收录、重刷答对移出（历史记录保留）、显示错误次数与最近时间

### AI 讲解（RAG）

- 多提供商：智谱（免费档 / 付费档）、DeepSeek、任意 OpenAI 兼容接口、分享到外部应用
- **教材 RAG**：检索本地教材库命中片段后，讲解必须依据教材并标注引用编号；教材未覆盖时经用户确认，可切换联网搜索（智谱 web_search）或模型知识回答
- SSE 流式输出、讲解自动保存（独立于题目自带解析字段）、删除 / 重新生成
- 数学公式 KaTeX 渲染

### 数据

- 题库、题目、错题、做题记录、收藏、教材、设置全部存储于本地 SQLite
- 版本化 JSON 备份导出 / 恢复（系统分享面板导出；恢复按稳定 ID 合并、单事务回滚）
- 可选云端备份：邮箱验证码登录，上传当前 JSON 到自建 FastAPI 服务，换设备后下载并按 ID 合并

## 技术要点

- **React Native + Expo SDK 57 + TypeScript（strict）**
- **SQLite（expo-sqlite）+ FTS5 trigram 中文全文检索**：教材 RAG 检索基于"3 字滑窗 OR 查询 + bm25 排序"，短查询自动回退参数化 LIKE
- **多 LLM 提供商抽象层**：统一 OpenAI 兼容协议封装（智谱 / DeepSeek / 自定义），自研 SSE 流式解析（XMLHttpRequest 增量读取）、思考模式控制、指数退避 + 抖动重试、错误码语义映射
- **确定性校验层（F2）**：模型输出经过结构化解析与修复 → 10 类确定性规则校验（结构 / 题型 / 选项 / 题干 / 去重哈希 / 置信度分级 / 视觉特征 / 答案缺失 / 来源 / 错误可见）→ 人工确认页复核；校验无效的题目不可直接入库
- **分层架构，离线可测**：`core`（纯逻辑） / `db`（SQLite 仓库层） / `services`（LLM、文档解析、检索、图像、云端 API） / `screens` 分层
- **可选全栈备份**：FastAPI + SQLAlchemy + SQLite，免密码邮箱验证码、30 天 JWT、20MB 上限与用户数据隔离；服务端只存 JSON，不解析题库
- **文档解析**：pdfjs、mammoth、自研 OOXML 与老版 .ppt（CFB + PowerPoint 记录流）解析器，支持内嵌图片提取
- **手势交互**：react-native-gesture-handler 实现图片框选 / 双指缩放 / 平移（含 Modal 内独立手势树的处理）
- **自动化测试**：7 套共 114 项客户端离线测试 + 后端 pytest，覆盖数据层（node:sqlite 执行真实 SQL）、解析器、校验规则、Prompt 构造、检索、备份恢复与鉴权/隔离
- **发布**：EAS 云端构建 APK 直接分发装机；云端备份为可选功能

## 项目结构

```
src/
  core/         纯逻辑层（领域模型、F2 校验、归一化、检索词、题干哈希）
  db/           SQLite 仓库层（schema 迁移、题目/题库/练习/教材/备份）
  services/     LLM 多提供商（含 SSE 流式）、视觉识别引擎、文档提取、图像处理
  screens/      页面（首页、识别确认、刷题、错题本、题库管理、文档导入、教材库、设置、备份）
  components/   通用组件（框选/缩放、教材绑定选择、公式渲染等）
  prompts/      模型指令资产（识别 / 结构化 / 讲解 / RAG / 答案文档，均含版本与 CHANGELOG）
tests/          离线验证脚本（114 项）
docs/           开发文档（里程碑交接、竣工核对、模型实测对比、M0 实测报告）
  artifacts/    开发过程留档（M1 依赖审计、启动日志、网络检查、工具配置，各含说明）
tools/          辅助脚本
server/         可选云端备份服务（FastAPI + SQLAlchemy + SQLite，含 pytest）
builds/         各次代码变更后的构建验证产物集合（每个子目录内附说明；仅用于确认可
                构建，与应用运行、数据备份无关，可作为开发日志浏览）
```

## 全栈架构（可选云端备份）

客户端默认完全离线运行。需要换机或多设备共用题库时，可在电脑或服务器上启动同仓库的 `server/`：

- 认证：邮箱验证码（10 分钟有效、一次性使用、发送限流），JWT 有效期 30 天
- 存储：每个账号只保留最新一份客户端备份 JSON，不解析题目
- 恢复：客户端先校验 `app` / `version`，再按稳定 ID 合并，不覆盖本机已有数据
- 限制：请求体 20MB，与客户端 `MAX_BACKUP_BYTES` 一致

启动、配置和测试步骤见 [server/README.md](./server/README.md)。手机与电脑需在同一局域网；生产部署必须更换 `JWT_SECRET` 并使用 HTTPS。

## 安装（Android）

到 [Releases](https://github.com/dzjsaber/paiti-rujuan/releases) 页下载最新的 APK 直接安装
（首次安装需允许"安装未知来源应用"）。不登录也可使用核心功能；云端备份才需要邮箱验证，AI 功能需在设置中填入
自备的智谱 / DeepSeek API Key（[获取入口见应用内设置页]）。

## 从源码运行

```bash
npm install
npx expo start        # 手机安装 Expo Go，扫码即可调试
```

跑测试（任选一套，共 7 套）与构建 APK：

```bash
npx tsx tests/m1b.verify.ts
npx eas-cli build -p android --profile preview
```

## 说明

- 个人学习与自用项目：API Key 由使用者自备，应用不内置任何密钥；Key 使用系统加密存储保存在本机，不进入代码、日志与备份文件
- AI 生成的讲解与答案为概率性输出，界面均带"仅供参考"提示，重要内容需人工核对
- 测试样本与部分开发过程产物不随仓库提供
